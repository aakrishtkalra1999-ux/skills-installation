# Industry primers: where to find sector context

When a new case lands in a sector, read these pages first for market size, key players, value chain, trends and jargon. **PDF page numbers.** A = IIMA (panorama reports, 2 pages each), C = IIM Calcutta (1 page each), F = FMS (1 page each), I = ISB (1 page each).

The figures in these primers are compiled by students and not independently checked (each book says so). Use them to orient yourself, then verify any number you put on a slide against an original source.
