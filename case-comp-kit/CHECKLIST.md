# Submission checklist

Tick every line before uploading.

## Rules
- [ ] Slide count matches the limit (does the cover count as a main slide?)
- [ ] File type and name exactly as asked (for example `TeamName_Competition.pdf`)
- [ ] No member names, institute names or logos on slides, in the file name or in the PDF's hidden details (check with `pdftotext` and by searching the PDF bytes)
- [ ] Team ID shown only if one was issued and the rules ask for it
- [ ] References fit inside the slide limit (linked files are usually ignored)

## Numbers
- [ ] Model integrity checks all read OK and there are zero formula errors
- [ ] Every number that appears on two slides is the same on both
- [ ] Bridges add up exactly with the rounding shown
- [ ] Nothing claimed that happens anyway, and nothing counted twice
- [ ] Units on every slide (footer line)
- [ ] Every assumption has a reason and a source; every benchmark was checked on its original page

## Story
- [ ] Slide 1 gives the answer and the tests it passes
- [ ] Every part of the problem statement is answered on a named slide
- [ ] Every headline is a full sentence stating the takeaway
- [ ] Every chart's claim matches what the chart shows
- [ ] Risks have warning signs and responses, not just a list

## Writing and look
- [ ] Humanised: plain words, short sentences, zero em or en dashes (scan the PDF text)
- [ ] Every abbreviation defined once
- [ ] Every slide viewed as an image: no overflow, no overlapping labels, no big empty areas
- [ ] One final read-through by the team, out loud
